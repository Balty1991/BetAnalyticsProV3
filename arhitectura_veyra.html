🏗️ syncRecommendationEngine() — motorul central

Rulează pe fiecare meci din ALL_MATCHES și decide cel mai bun pariu

1. getSupportedMarketTypes()
→ [over15, over25, under35, btts, dc1x, dcx2, dc12]
2. buildMarketCandidate(m, type)
→ calculează edge, adjProb, value
3. Sort candidați
→ după ticketScore, value, adjProb
4. m.bestBet = eligibleCandidates[0]
→ câștigătorul
analysisState rezultat:
✅ ELIGIBLE ⚠️ CONTRADICTED 🧠 FILTERED_OUT ⛔ NO_EDGE 🛰️ NO_ODDS

🎯 passesSelectionFilter(m) — filtru de bază

Condiția minimă ca un meci să fie afișat în Meciuri (filtrul "Toate")

// 3 condiții obligatorii:
m.bestBet !== null // are un pariu valid
m.analysisState === 'ELIGIBLE' // a trecut filtrul motor
isMatchStillDisplayable(m) // meciul nu a început de >90min
isMatchStillDisplayable: data meciului + 90 min > acum
Piețe acceptate: Over 1.5GOver 2.5GUnder 3.5GBTTSDC 1XDC X2DC 12
3 · Schema unui obiect meci — ALL_MATCHES[i]

📋 Câmpuri de bază

// Identitate
eventId: number // ID unic BSD API
home: string // "Spain"
away: string // "Cabo Verde"
league: string // "World Cup 2026"
leagueTier: string // "top"|"standard"|"avoid"|"neutral"
date: ISO string // "2026-06-15T17:00:00Z"
status: string // "notstarted"|"live"|"finished"

// Probabilități (0-100%)
prob_over_15: number // ex: 87.3
prob_over_25: number // ex: 58.1
prob_under_35: number // ex: 79.2
prob_btts_yes: number // ex: 45.6
prob_home_win: number // ex: 43.0
prob_draw: number // ex: 29.0
prob_away_win: number // ex: 28.0

// Cote piață
odds_over_15: number // ex: 1.38
odds_over_25: number // ex: 1.92
odds_btts_yes: number // ex: 2.88

📋 Câmpuri calculate de JS (după syncRecommendationEngine)

// Stare analiză
analysisState: string // ELIGIBLE|NO_EDGE|NO_ODDS|...
smartScore: number // scor compozit 0-100
verdict: string // "safe"|"moderate"|"risky"
riskTier: string // "Safe"|"Balanced"|"Value"
why: string // explicația predicției

// Cel mai bun pariu selectat
bestBet: {
  type: "over25" // market key
  label: "Over 2.5G" // text afisat
  adjProb: 58.1 // probabilitate ajustată %
  odds: 1.92 // cota curentă
  edgePct: 7.4 // avantaj față de piață %
  value: 0.12 // EV (Expected Value)
  verdict: "bet" // "bet"|"risk"|"avoid"
  smartScore: 74 // scor decizie
}

// Toți candidații eligibili
eligibleCandidates: Array // ordonați după score
isEnriched: boolean // a primit date îmbogățite
